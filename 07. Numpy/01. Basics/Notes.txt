1. NUMPY -->
    (Numerical Python) is a Python library,
    used for numerical and scientific computing.
    But can also work for other datatype.

    It provides:
    - Multidimensional arrays
    - Mathematical operations
    - Linear algebra
    - Statistical operations
    - Random number generation
    - Fast numerical computation

2. Why do we need NumPy?
    Lists are not designed for large-scale numerical computation.
    NumPy provides an 'ndarray', which is optimized for numerical operations.

3. Representation :
    Lists = [n1,n2,n3,n4,n5]

    Numpy = [n1 n2 n3 n4 n5]
    Numpy = np.array(Numpy)

4. Array --> Homogenous type of datatype, stores only one datatype at a time.
    Thus, Numpy is faster then lists.
