# OOP --> Object oriented programming.
    A way\Methode to write a code. 

1. class: Basic blueprint template that defines the properties.
2. Object: Specific instance of that class.
    It is created using the class and contains actual data.

This methode is used to deal with a large amount of data.

-------------------------------------------------------------------------------------------------------------------

# Syntax -->

class ClassName:
    def __init__(self, parameter1, parameter2):
        self.parameter1 = parameter1
        self.parameter2 = parameter2

    def method_name(self):
        # statements
        pass


# Creating objects
object1 = ClassName(value1, value2)
object2 = ClassName(value3, value4)

# Accessing attributes
print(object1.parameter1)

# Calling methods
object1.method_name()
